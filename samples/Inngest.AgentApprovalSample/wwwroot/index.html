An agent that asks before it acts

The support agent of a small coffee shop. It looks orders up on its own, but every refund and every email waits for your approval, for as long as it takes.

  • Waits in InngestThe run pauses on a step, not in memory. Restart the app while it waits, then approve.
  • Steer it with a noteReject with a note such as “make it shorter”, and the agent tries again.
  • Acts exactly onceAn approved refund is a step. A retry later in the run never refunds twice.

Give the app a model key, then restart it. The key stays in your user secrets, outside the repository.

dotnet user-secrets set Anthropic:ApiKey sk-ant-... --project samples/Inngest.AgentApprovalSample

Orders and emails are made up and live in the app's memory. Nothing is charged or sent.
